Проект содержит в себе следующие директории и файлы:

1.Директория allure_results - oтчёты allure в формате JSON.
2.Директория locators - локаторы страниц:
3.base_page_locators - общие локаторы для сайта
4.main_page_locators - локаторы для главной страницы
5.order_page_locators - локаторы для страницы заказа
6.Директория pages - директория, содержащие в себе страницы проекта:
7.base_page - общие методы для всех страниц сайта
8.main_page - главная страница
9.order_page - страница заказа самоката
10.Директория tests - директория с тестами, содержит следующие тестовые сценарии:
11.test_expanding_drop_list - тестирование выпадаюшего списка на главной странице
12.test_order_scooter - тестирование создания заказов с двух точек входа, перехода на главную страницу, редирект на дзен

Файлы:
-.gitignore - игнорируемые файлы и директории
-conftest - файл фикстур
-data - файл данных
-helpers - генерируемые данные
-requirements - файл с необходимыми библиотеками
